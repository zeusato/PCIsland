# PCisland v0.1.3

Bản v0.x phát hành theo yêu cầu chủ dự án ngày 2026-11-02: nhạc tập trung tải theo yêu cầu, hộp chào lần đầu, Spotify/SoundCloud, nút chia sẻ, tùy chọn nút island, dọn dẹp mở rộng và các sửa lỗi kéo thả/note.

## Thay đổi

- **Nhạc tập trung ([ADR-023](https://github.com/zeusato/PCIsland/blob/v0.1.3/docs/06-decision-log.md)):** Cài đặt › Pomodoro › Nhạc tập trung liệt kê gói từ release mới nhất của [zeusato/pcisland-sounds](https://github.com/zeusato/pcisland-sounds/releases/tag/focus-sounds-v1). Hiện có `focus-sounds-v1`: Lo-fi & Jazz (tập trung, 7 bài), Ambient (tập trung, 9 bài), Thư giãn (nghỉ, 4 bài), 97 MiB MP3. Tải có tiến trình/hủy, kiểm kích thước + SHA-256 từng file; Pomodoro phát gói tập trung khi làm việc, gói nghỉ khi nghỉ, xáo và lặp. Bộ cài không chứa nhạc.
- **Hộp chào lần đầu:** hỏi tải yt-dlp (video YouTube) và các gói nhạc, tick sẵn, chỉ tải khi bấm. Bỏ qua được; tải sau trong Cài đặt.
- **Spotify Web:** danh sách phát (trước/đang phát/tiếp theo) có tên bài, repeat tắt/cả list/một bài qua nút của trang.
- **SoundCloud:** danh sách "Next up", tìm kiếm bài, repeat qua nút của trang, link bài sạch query.
- **Chia sẻ:** nút cạnh repeat chép link bài/video đang phát vào clipboard (chỉ http/https, không kèm thông tin đăng nhập).
- **Island:** nút chức năng cùng kích thước, tên một dòng, trạng thái chuyển vào tooltip. Cài đặt › Nút trên island ẩn/hiện từng nút.
- **Dọn dẹp ([ADR-022](https://github.com/zeusato/PCIsland/blob/v0.1.3/docs/06-decision-log.md)):** thêm nguồn rác lớn, Thùng rác, cache Windows Update (hỏi UAC), danh sách app nền ngốn RAM để đóng (xác nhận từng app). Tác vụ đang chạy giữ tiến trình khi rời và quay lại island.
- **Sửa lỗi:**
  - Kéo file từ Explorer vào island hiện dấu cấm, nay thả được.
  - Kệ file khi thả bị cắt, mất nút thao tác.
  - Note desktop không đóng được cửa sổ.
  - Ô tick lệch khi đổi cỡ chữ.

## Kiểm tra và giới hạn

Trước đóng gói: 269 test Rust đạt (4 ignored); vitest đạt; fmt, clippy all-targets, svelte-check/eslint/i18n 574 khóa và frontend build đạt. Kéo file vào island kiểm bằng mô phỏng OLE drag trên bản debug. Release nhạc kiểm URL manifest `latest` và hash một file tải về.

Chưa nghiệm thu trên exe:
- tải/hủy/xóa gói nhạc và phát theo pha Pomodoro;
- hộp chào lần đầu;
- Spotify/SoundCloud qua tài khoản thật (chủ dự án tự thử, tránh thao tác giống bot);
- dọn Windows Update qua UAC, đóng app nền;
- nút chia sẻ, ẩn nút island.

Gate G0 chưa đóng; bản này chưa ký số.

## Tải và nâng cấp

- `PCisland-0.1.3-setup.exe`: bộ cài NSIS theo tài khoản Windows.
- `PCisland-0.1.3-portable.zip`: giải nén rồi chạy `PCisland.exe`, giữ thư mục `data` cạnh exe.
- Mỗi gói có `.sha256`; đối chiếu bằng `Get-FileHash <tên-file> -Algorithm SHA256`.

Windows 11 x64, Microsoft Edge WebView2 Runtime. Thoát bản cũ qua tray trước khi nâng cấp. Với portable chỉ thay exe, không thay thư mục `data` đang dùng bằng thư mục trống trong ZIP. Gói nhạc tải về nằm trong `data/focus-sounds` (portable) hoặc thư mục dữ liệu app.
